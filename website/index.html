⚠️ COMMON GOTCHA
Why didn't mytools img2web -a work? Two quick reasons:
  1. No mytools prefix needed for individual tools: mytools opens the interactive menu launcher, while each tool (img2webp, vidglue, vid2webm, wav2mp3, etc.) is run directly by its own name. (Note: mytools <tool> [flags] now also forwards automatically as a convenience!)
  2. The image tool ends with a p: It is named img2webp (for WebP), not img2web.
STEP 01
Go to Your Files Folder

Open Terminal and move into the folder with your media. Tip: Type cd with a space, drag-and-drop your folder from Finder into Terminal, and press Enter.

❯cd ~/Pictures/MyPhotos
STEP 02
Run the Tool Directly with Flags

Combine custom flags before -a (all files in current folder) or before filenames. Add -n (--dry-run) anytime to preview safely without changing files.

❯img2webp --width 1200 -q 90 -a
STEP 03
Or Use Wizard Mode (-i)

Don't want to memorize flags? Run img2webp -i, vidglue -i, vidglitch -i, vidcuts -i, videoeffects -i, or videorandfram -i. It previews file metadata, walks you through every setting, prints the exact Equivalent command, and lets you copy it to clipboard!

❯videoeffects -i

Installation & Dependency Health

Zero-friction setup. Pure Bash symlinks in ~/.local/bin and automatic Zsh completion integration in ~/.zfunc.

01
Clone Repository

Clone the repository to your preferred coding directory on macOS.

❯git clone https://github.com/cocreating/mytools.git
02
Run Install Script

Links all commands to ~/.local/bin and registers completion functions in ~/.zshrc.

❯cd mytools && ./install.sh
03
Run Doctor Healthcheck

Verifies all dependencies and installs any missing Homebrew packages automatically.

❯mytools doctor --install
